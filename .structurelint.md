# structurelint Setup

This project uses [structurelint](https://github.com/Jonathangadeaharder/structurelint) with **MAXIMUM ENFORCEMENT** - all 6 available phases enabled.

## What is structurelint?

structurelint is a next-generation linter that validates:

- **Architectural Integrity**: Layer boundaries and clean dependencies
- **Code Quality**: Evidence-based complexity metrics
- **Test Coverage**: Ensuring critical code is tested
- **Dead Code**: Orphaned files and unused exports
- **Project Structure**: Directory organization and naming
- **CI/CD**: GitHub workflow enforcement

## Enabled Features

This project has **ALL 6 PHASES** of structurelint enabled - one of the most comprehensive setups possible:

### Phase 0: Filesystem Linting ✅
- Directory depth limits (max 5 levels)
- File count restrictions (15 per directory, 20 for screens)
- Naming conventions (PascalCase, camelCase)
- Disallowed patterns (temp files, backups, swap files)

### Phase 1: Architectural Layer Enforcement ✅ **NEW!**
**8-layer React Native architecture defined and enforced:**

\`\`\`
data (no dependencies)
  ↓
core (no dependencies)
  ↓
utils (no dependencies)
  ↓
services → utils
  ↓
context → services, core, utils
  ↓
hooks → services, context, core, utils
  ↓
components → hooks, context, core, services, utils
  ↓
screens → ALL LAYERS
\`\`\`

**What this prevents:**
- ❌ Circular dependencies
- ❌ Utility functions importing from services
- ❌ Core logic depending on UI components
- ❌ Services importing from context/hooks
- ✅ Clean, unidirectional data flow

### Phase 2: Dead Code Detection ✅ **NEW!**
- **Orphaned file detection**: Finds files not imported anywhere
- **Unused export detection**: Catches exports never used
- **Pragmatic exemptions**:
  - Screens (used by React Navigation registry)
  - Generic UI components (reusable library)
  - Data files (static configuration)

### Phase 3: Test Validation ✅
**Adjacent test files required** for critical business logic (14 test files created)

### Phase 5: Evidence-Based Metrics ✅
- **Cognitive Complexity** (max 15): Measures maintainability
- **Halstead Effort** (max 100k): Measures cognitive load
- Based on peer-reviewed research

### Phase 8: GitHub Workflow Enforcement ✅ **NEW!**
- Requires test workflows on PR/push
- Requires quality workflows (linting, formatting)

## Installation

\`\`\`bash
git clone https://github.com/Jonathangadeaharder/structurelint.git
cd structurelint
go build -o structurelint ./cmd/structurelint
sudo cp structurelint /usr/local/bin/
\`\`\`

## Usage

\`\`\`bash
npm run lint:structure           # Run all checks
npm run lint:structure:watch     # Watch mode
structurelint .                  # Direct command
structurelint . --format json    # JSON output
\`\`\`
